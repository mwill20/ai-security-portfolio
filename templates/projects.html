ThreatPrism — Guardrail-First SOC Investigation Pipeline

AI-assisted SOC analysis with deterministic guardrails and evidence-first reporting

48% reduction in analyst investigation time

The Challenge

Security analysts face repetitive manual event correlation across fragmented telemetry sources, with investigation workflows averaging 30-45 minutes per alert batch. Traditional automation breaks analyst trust when tools produce unreliable outputs.

The Solution

ThreatPrism is a guardrail-first SOC investigation pipeline that automates IOC extraction, MITRE ATT&CK mapping, severity and confidence scoring, next-step generation, and analyst context delivery while keeping production details proprietary.

Architecture Approach

Three-layer guardrail enforcement: (1) deterministic validation for known patterns, (2) semantic schema enforcement preventing malformed outputs, (3) policy-based controls enforcing organizational rules.

Demonstrated Impact

  • 48% reduction in investigation time (30-45 min → ~6 min per batch)
  • Zero hallucinated actions through strict guardrail enforcement
  • Full auditability with provenance tracking for compliance
  • Designed for production SOC environments

PLAYBOOK KIT

Rapid Exposure Response (RER) Kit

Emerging-vulnerability playbook: contain fast with compensating controls, remediate, verify, and hunt. Run with Microsoft 365 Copilot.

S0–S7 eight-stage standing protocol, each stage with an entry and exit gate

The Challenge

A critical vulnerability drops and the response has to start before a patch exists: who owns each exposed asset, which compensating control buys time, what evidence proves a fix, and whether anything was already exploited. Most of that work crosses teams that do not report to security.

The Solution

A generic, reusable playbook kit: a standing protocol from intake to close, one Event Pack per vulnerability that maps the advisory onto the playbook, and libraries of compensating controls, verification recipes, and SIEM-agnostic retro-hunt hypotheses with decision tables for exposure grading, control selection, and evidence standards.

Architecture Approach

One-way flow: GitHub to work, never back. Tagged releases ship a zip with SHA256 checksums and GitHub build attestations, extracted into a restricted SharePoint site as a read-only upstream copy beside the organization's filled edition. An M365 Copilot agent grounds on both and must cite a table row for every grade, control, and hunt; a pasted advisory is treated as data, never as instructions.

What Ships

  • Eight-stage playbook, Event Pack template, and after-action report template
  • Control, verification, and hunt libraries (H1–H7) with four decision tables
  • Copilot agent instructions, prompt pack, and Power Automate flow specs
  • Three synthetic drills with answer keys and a scoring sheet
  • Pre-commit leak guard and a cross-reference checker run in CI
Note: The repository holds templates only. No organization data is ever committed; every filled copy lives in the organization's own tenant.

VALIDATED SECURITY RESEARCH

AI DevSecOps Platform — 5-Layer Security Mesh

Validated AI security engineering research for detecting unsafe code-generation patterns

57 adversarial test cases validated

The Problem

Traditional static analysis tools miss AI-specific threats (prompt injection, model poisoning, shadow code modifications), while pure LLM-based security tools lack deterministic guarantees and audit trails required for CI/CD workflows.

The Solution

Validated AI security engineering project for detecting unsafe patterns in AI-generated code. Combines deterministic controls, semantic taint tracking, ShellGuard, LLM reasoning with Pydantic constraints, and provenance concepts.

Key Innovation: Taint Handshake Protocol

AST provides factual data flows (deterministic), LLM provides semantic intent analysis (contextual). Shadow Code detection flags unauthorized AI modifications through provenance verification. Semantic Drift tracking monitors AI vs. AST disagreements as red-team radar for model blind spots.

Validation Results:
  • Tested across 57 adversarial scenarios
  • Detection patterns mapped to OWASP LLM Top 10
  • Detects washed secrets & logic bombs
  • CI/CD-ready with sys.exit(1) on CRITICAL
