# AGENTS.md

Instructions for AI coding assistants working in this repository.

## What this project is

A Flask app used **only as a build-time template engine**. Frozen-Flask renders every
route to flat HTML in `build/`, and GitHub Pages serves that. There is no production
server, no database, and no request handling. Read `docs/ARCHITECTURE.md` before making
structural changes.

## Read this before editing `templates/projects.html`

The file is **half hand-written HTML, half data-driven**:

- The **Featured** block at the top is hand-authored and not generated from
  `projects_data.py`.
- Everything below is a `{% for key, category in projects.items() %}` loop.

A previous `{% if key != 'mcp' %}` guard made the `mcp` section of `projects_data.py` dead
data — edits to it silently changed nothing on the live site. That guard is gone. Do not
add a hand-written category block; it recreates the trap.

## Hard rules

1. **Never invent a project description.** Every card's text must be derived from that
   repository's actual README or its GitHub description. If neither exists, say so and ask
   — do not infer a project's purpose from its name.
2. **Never state a metric that is not in the source.** No accuracy figures, recall rates,
   percentages, or deployment claims unless they appear in that project's own README. Do
   not describe anything as "production-ready" or "deployed" without evidence.
3. **Never add a placeholder link.** `"url": "#"` is rejected by
   `tools/verify_catalogue.py`. If there is no real destination, omit the link.
4. **Pin every dependency to an exact version.** `requirements.txt` uses `==`. A `>=`
   range silently changes published output.
5. **Do not commit `build/`.** It is generated by CI and gitignored.
6. **Do not commit or push without being asked.**

## Adding a project

Add to the appropriate category list in `projects_data.py`:

```python
{
    "title": "Project Name",
    "description": "Derived from the project's README.",
    "icon": "fas fa-shield-alt",
    "tech": ["Python"],                    # optional
    "links": [
        {"label": "View on GitHub", "url": "https://github.com/...", "class": "btn-primary"}
    ],
}
```

`title`, `description`, `icon`, and a non-empty `links` list are required —
`project.links[0].url` is dereferenced without a guard and will raise at build time
otherwise. Do not add a `badge` key; the loop ignores it.

Category keys must stay in the same order as the filter buttons:
`mcp, security, agents, ml, cloud, fun`.

## Verify before reporting done

```bash
python tools/verify_catalogue.py
python freeze.py
```

`freeze.py` succeeding is the real test — it exercises every route and every template
branch. A change that looks correct in the data file but breaks the freeze is not done.
